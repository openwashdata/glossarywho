# themes: Table of Thematic Areas from https://www.who.int/publications/i/item/9789240105485

A table that assigns thematic areas to definitions included in the WHO
Glossary (https://www.who.int/publications/i/item/9789240105485)

## Usage

``` r
themes
```

## Format

A tibble with 217 rows and 2 variables

- Thematic Area:

  Thematic Area

- Term:

  Term in the Glossary
