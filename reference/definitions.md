# definitions: Definitions of terms in the WHO Glossary (https://www.who.int/publications/i/item/9789240105485)

This datasets contains all terms and their definitions as defined in the
WHO Glossary.

## Usage

``` r
definitions
```

## Format

A tibble with 207 rows and 2 variables

- Term:

  Term in the Glossary

- Description:

  Description of the term
